# Password Strength Analyzer

A modern Python-based cybersecurity tool that analyzes password strength using GUI and security validation techniques.

## Features
- Password strength checking
- Uppercase and lowercase validation
- Number detection
- Special character detection
- Password strength meter
- Modern dark-themed GUI

## Technologies Used
- Python
- Tkinter

## How to Run
1. Install Python
2. Download the project
3. Run:
python password_strength_analyzer.py

## Project Objective
This project was developed as part of a cybersecurity virtual internship to understand password security and strength analysis concepts.
